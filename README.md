 Pokemon App 🧩

A React + TypeScript app to browse Pokémon with filtering, sorting, favorites, and infinite scroll.

## 🚀 Features
- Fetch Pokémon data from PokéAPI
- Add Pokémon to favorites
- Filter and sort by type or name
- Infinite scroll and modal details

## 🛠️ Technologies
- React
- TypeScript
- Tailwind CSS
- Context API
- Vite

## 🏃‍♂️ Run Locally
- git clone https://github.com/YOUR_USERNAME/pokemon-app.git
- cd pokemon-app
- npm install
 -npm run dev
